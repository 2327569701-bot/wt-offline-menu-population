# 主菜单在线人数 1.0.1

在离线版主菜单左上角显示本地随机生成的在线人数和进行中的战斗数。每分钟刷新，进入战斗后暂停。

[查看发布说明](https://github.com/2327569701-bot/wt-offline-menu-population/releases/tag/v1.0.1)

## 安装

1. 退出游戏并解压上面的 ZIP。
2. 把包内的 `Mod`、`backend`、`tools`、`work` 复制到 `WarThunderOffline.exe` 所在目录，按包内说明覆盖同名文件。
3. 启动游戏。可在模组管理器中启停。

适用于与本项目同构建的 War Thunder Offline 2.59.0.92。若也要安装穿越者，先安装本包。与 DTC201-125 合用时，需保留加载器的 `char` 资源和 `ztz99aDtc201` 支持。
